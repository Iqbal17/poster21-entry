**Eldara — Isle Above the Clouds.** A travel poster for a place that
isn't there: an island whose cliffs rise out of a sea of clouds, a
striped lighthouse sweeping its beam over the dusk, and a cable car
descending into the clouds. The promise of a stay above the weather,
where the sea ends in sky.

`main.py` draws the whole poster procedurally (standard library only,
no network, no fonts from the system — the lettering is a hand-built
5x7 pixel font) and writes a 1024x1024 PNG to `$MAKEFUN_OUTPUT_DIR/
entry.png`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/poster-out python3 main.py
```
